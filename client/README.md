# 🏋️‍♂️ FORMANCE — Built for Coaches. Loved by Clients.

Welcome to **FORMANCE**, a streamlined platform designed for personal trainers and coaching professionals to manage their clients, sessions, progress tracking, and payments — all in one place.

Built to be **modular, intuitive, and client-focused**, FORMANCE gives you the tools to grow your coaching business without technical complexity.

---

## 🌟 Key Features

- 📆 **Session Scheduling** — Easily create and manage training sessions with built-in calendar support.
- 👥 **Client Management** — Add clients, track their progress, and monitor engagement over time.
- 💸 **Automated Payments** — Recurring and one-time payments with integrated billing support.
- 🔔 **Smart Reminders** — Send automated session reminders, payment alerts, and goal updates via email or SMS.
- 📈 **Progress Tracking** — Track workouts, body metrics, nutrition plans, and more.
- 🎨 **Branding & Customization** — White-label your experience with custom logos, colors, and messages.
- 📂 **Resource Sharing** — Upload workout plans, videos, documents, or diet charts per client.
- 🧩 **Scalable & Secure** — Manage multiple coaches, teams, and clients with role-based access controls.

---

## 🚀 Quick Overview

### 1. Trainer Signup
- The first user becomes the **admin trainer**.
- Can manage all global settings, clients, team members, and integrations.

### 2. Teams & Assistants
- Add assistant coaches or team members to manage sessions and clients together.

### 3. Clients
- Store everything in one place:
  - Personal details & goals
  - Sessions attended
  - Progress reports
  - Payment history
  - Shared resources

### 4. Sessions
- Schedule one-on-one or group sessions.
- Track attendance and notes.
- Sync with Google/Outlook Calendar (optional).

### 5. Automated Billing
- Set up recurring subscriptions or per-session payments.
- Integration-ready with Stripe, Razorpay, or PayPal.
- Generate invoices and receipts.

### 6. Notifications
- Auto-send:
  - Session reminders
  - Payment due alerts
  - Motivation or progress nudges
- Customizable email/SMS templates.

## 🏗️ Tech Stack

| Layer     | Technology                                                  |
|-----------|-------------------------------------------------------------|
| Frontend  | React, Vite, TailwindCSS, ShadCN UI, React Router, Zustand |
| Backend   | NestJS, PostgreSQL, Redis                                   |
| Auth      | JWT + Role-Based Access                                     |
| Forms     | React Hook Form + Zod                                       |
| Notifications | Email + SMS (via Twilio/Mailgun)                         |
| Payments  | Stripe, Razorpay (optional)                                 |
| CI/CD     | GitHub Actions + Vercel/Turborepo                           |
